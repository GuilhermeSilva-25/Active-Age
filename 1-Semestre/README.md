# 📁 1º Semestre: Fundamentação, Design e Prototipagem

## 🎯 Objetivo
Estruturar a base do **Active Age**. O foco deste semestre é a engenharia de requisitos, a modelagem de dados e a criação de uma interface acessível (focada na terceira idade) utilizando desenvolvimento web estático.

## 📚 Disciplinas Integradas
* Engenharia de Software I
* Design Digital
* Desenvolvimento Web I
* Modelagem de Banco de Dados

## 🚀 Entregas Planejadas
- [ ] **Documentação e Requisitos:** Casos de Uso e Diagramas UML.
- [ ] **Modelagem de Dados:** Diagrama Entidade-Relacionamento (MER).
- [ ] **Prototipagem e Front-End:** Wireframes e telas iniciais (HTML/CSS) baseadas em diretrizes de acessibilidade (WCAG AA).
