# 📁 1º Semestre: Fundamentação, Design e Prototipagem
**Status: Concluído** ✅

## 🎯 Objetivo
Estruturar a base arquitetural e visual do **Active Age**. O foco deste semestre foi a engenharia de requisitos, a modelagem de dados e a criação de uma interface acessível (focada na terceira idade) utilizando desenvolvimento web nativo.

## 📚 Disciplinas Integradas
* Engenharia de Software I
* Design Digital
* Desenvolvimento Web I
* Modelagem de Banco de Dados

## 🚀 Entregas Realizadas

### 1. Documentação (`/docs`)
* **Requisitos:** Levantamento completo de Requisitos Funcionais, Não Funcionais e Regras de Negócio, incluindo o fluxo financeiro de telessaúde.
* **Casos de Uso:** Mapeamento das interações dos atores (Paciente, Médico e Administrador) com a plataforma.
* **Modelagem de Dados:** Estruturação das entidades do sistema, preparando o terreno para a implementação de bancos de dados relacionais e não relacionais nos próximos semestres.

### 2. Identidade Visual (`/assets`)
* Criação da logo oficial do Active Age, transmitindo longevidade, cuidado e saúde através de uma paleta de cores acessível e tipografia amigável.

### 3. Prototipagem Funcional (`/src`)
* Construção da interface em **HTML5, CSS3 e JavaScript (Vanilla)**.
* Uso de **Bootstrap 5** para responsividade e **SweetAlert2** para feedback visual.
* **Simulação de Back-End:** Implementação de lógica via `localStorage` do navegador para validar os fluxos de **Cadastro**, **Login** e redirecionamento dinâmico para o **Dashboard** de acordo com o perfil do usuário (Paciente/Médico), sem a necessidade de um banco de dados real nesta etapa.

## 💻 Como executar o protótipo
Como o projeto deste semestre foi construído com tecnologias web nativas, não é necessária nenhuma instalação complexa.
1. Faça o clone ou baixe este repositório.
2. Navegue até a pasta `1-Semestre/src`.
3. Dê um duplo clique no arquivo `index.html` para abri-lo diretamente no seu navegador.
4. Teste criar uma conta e fazer login!
